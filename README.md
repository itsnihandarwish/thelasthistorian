# The Last Historian v0.7

Complete birthday game build through the Observatory and final birthday ending.

Included:

* Level One with five archive gems
* Ottoman question, Steppe Chronicle and Mongol Empire question
* Bard Crystal with the supplied singing recording
* Fahad and Doggy Bacha portrait reward
* Sword reward and Level Two combat
* Zombies, aliens and Sir Reginald
* Saturn portal riddle
* Observatory arrival and exploration
* Touch friendly working telescope with Jupiter, Saturn, Io, Ganymede and Titan
* Swipe and button telescope navigation
* Short playable routes on Io, Ganymede and Titan
* Doggy Bacha discovery on Titan
* The First Sky archive for 10 October 1999 in Kuwait
* Full gravity poem split into short tap through screens for phone reading
* Final birthday statistics screen

Mobile is the primary target. All essential actions work by tap.

Desktop controls:
A or Left Arrow moves left
D or Right Arrow moves right
W, Up Arrow or Space jumps
X or K attacks after acquiring the sword

Run locally:
Open the folder in VS Code. Right click index.html and choose Open with Live Server.

Publish later:
Upload the folder contents to a GitHub repository and enable GitHub Pages.
